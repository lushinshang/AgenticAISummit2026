這是個非常、非常有趣的演算法。它在二〇〇一年被 NIST 標準化，是一種疊代演算法，總共執行十輪。基本上，它會從你或某個程式那裡取得一個輸入和一把金鑰，然後主要包含四個部分。其中一個叫代換（substitution），另一個是……，其他的則類似做排列（permutation）。代換盒（substitution box）做的事情，是把一個輸入映射到另一組輸出。接著把這些位元搬移，加上金鑰，也就是加上你對輸入所套用的金鑰函數，這是一個疊代演算法，意思是它會多次重複做這件事，在最簡單形式的 AES 中，大約會執行十輪。先澄清一下，我們並沒有破解 AES，如果有人真的破解了 AES，那大概等於破解了整個網際網路，所以我接下來要講的是非常學術性的工作。我們特別聚焦在縮減輪數的 AES 上，也就是不做完整十輪，而是只做七輪。這是學術界通常會研究的對象，因為比較容易處理，也比較有可能找到一些改進。而如果你想攻擊七輪的 AES，存在的最笨演算法，也就是暴力嘗試每一把金鑰，計算複雜度大約是二的一百二十八次方次運算，這需要的時間比我們的太陽變成新星（nova）所需的時間還長，所以根本不可能做到。

目前存在最好的演算法出現在二〇一三年，大約需要二的九十九次方次運算，換算下來大概要花個二十萬到兩萬……差不多那個等級的年數才能跑完。這並不是因為沒人努力，這個領域有好幾項研究都試圖破解它，算是被相當充分研究過的問題。而我們現在得到一個數字，我們展示了一種攻擊，能在縮減輪數的 AES 上做到大約二的八十九次方，或者類似的數量級，實際上怎麼算要看你的計算方式。實際上我們也做了一些實證評估，速度大概快了兩百到八百倍。所以換算下來大概是……一千年左右。我不知道這有多重要，但，嗯，就是這樣。

那這實際上是怎麼運作的？攻擊密碼演算法的方式，通常是嘗試找出輸入和輸出之間的關係，而不用真的去執行整個演算法。AES 特別使用了一個特定公式來做代換：先取一個輸入，在某個體（field）裡把它反轉，然後再做縮放與位移。假設你有一個物體，你把它縮放又位移，留下來的東西是這個形狀之間的比例維持不變，只是被位移和放大而已。模型理解到 AES 的 S 盒（S-box）具有這種特性，並利用這一點想出了演算法。這是一個非常、非常複雜的方法，我試著在兩分鐘內做個總結。

有趣的是，我的投影片動畫顯然沒有跑起來，但我還是會照著講。這裡真正的動機，是想理解隨著我們逐步把代理型 AI 導入到資訊實體系統（cyber-physical systems）中，我們該如何管理它。傳統上，safety 與 security 是分開評估的，各自獨立進行。但以我們現在談的這類系統來說，網路攻擊可能會在整個技術系統中連鎖擴散，透過感知系統等等，最終導致不安全的後果。我們用「危害」（hazard）這個詞，指的是威脅到人身、設備或人員安全的事物。導入 AI 之後，security 與 safety 的問題都出現了相當大的變化。我們的攻擊面變得大得多，除了作業系統之外，我們還有訓練管線（training pipeline）。

但事實上，如果你有一套實體系統，那麼實體環境本身也是我們攻擊面的一部分。這裡有個小例子，不是我們做的，是我們借用別人的案例：他們拿一個 AI 演算法，訓練它去偵測感知系統的弱點。結果它做的事情，是印出貼紙貼在停止標誌上，讓感知邏輯誤判成時速四十五英里的速限標誌。在實驗室裡準確率達百分之九十三，在真實世界中則有百分之八十三。所以這類實體攻擊是真實存在的。Safety 是建立在因果模型之上的，本質上我們一直在做的，是建構能代表這些因果結構的世界模型，我們稱之為 SCWM，也就是結構因果世界模型（Structure Causal World Models）。

AI 領域對於自動學習世界模型很感興趣。而我們這些是我們自己明確描述出來的東西，並實際把 security 綁進這些結構裡。舉個例子，這不是我們實際在做的真實系統，但相當有代表性：一艘無人水面艦艇，依照 IMO（國際海事組織）的定義，在某種程度上算是自主的，意思是它大部分時間是遠端遙控操作，但必要時也能在沒有遠端互動的情況下自主運作。所以我們用一個 YOLO 物件偵測器建了一套模擬系統，然後還有一個我們稱為「失聯保護模組」（dropout protection module）的東西。如果它失去與遠端操作中心的通訊，就會退回到完全自主的功能來操作船艦。

這種情況可能因為各種原因發生，例如干擾（jamming）等等。還有其他我們必須擔心的事，AIS（自動識別系統）是用來告訴其他船艦你的位置的東西，這也可以被偽造（spoof）。還有很多其他要擔心的事。所以我們在這裡談的是一種複合攻擊。我剛才說過我們可以做實體攻擊，這個例子則是同時結合傳統的數位攻擊——網路入侵——以及實體攻擊。我在這裡列出了我們建構的模擬系統中一項漏洞利用的一些細節。細節本身不是那麼重要，但這個攻擊的本質是對遠端操作中心發動阻斷服務攻擊（denial-of-service），讓它無法再控制船艦。

這麼做的直接效果，是船艦上的這個保護模組會啟動，它會自主運作，繼續沿著約定好的路徑，穿越那片海域。但另一方面，我剛才展示過那個實體攻擊的例子：這是一艘在海上的無人水面艦艇，你可以操作一架無人機（UAV），在攝影機前放一張影像，讓它要嘛完全偵測不到那艘船，要嘛把它判斷成完全不同的東西，因而需要採取不同的迴避動作。這代表這艘正在接近的油輪，要嘛完全沒被偵測到，要嘛被完全誤判。如果只單獨做這兩件事的其中一件，結果其實是安全的。

如果我只是退回到 DPM（失聯保護模組），船艦仍然能安全運作；如果我只是偽造攝影機畫面，但遠端操作人員實際上會發現，因為他們有資料回傳，會採取適當的行動。但如果我把這兩件事同時做，最後就會製造出一個不安全的狀態。這張小圖的用意，是要呈現這些失效，也就是那兩個最初的攻擊，是如何在系統中傳播，最終導致船艦持續在移動、卻不知道有一艘油輪就在前方，因此不會採取任何迴避動作。所以我們現在有兩艘船正朝著相撞的航線前進。我剛才說過我們會建模這件事，這個結構因果世界模型的概念，總共有四層。最上層是本體論（ontology）。

它描述的是在我所處理的這個世界裡，真正重要的那些事物。舉個例子，這裡是浪高。這很重要，因為浪對船艦施加的力量，會改變船艦的可操縱性。在這一層之下，我們接著會試著對不確定性建模。這件事其實在很多方面都很重要，但在這個特定情境下，你沒辦法確切算出浪型跟船艦互動的結果會是什麼，所以這是關於海況會如何影響船艦運動的不確定性。這會被映射到不確定性的某些邊界上。所以在最底層，對於喜歡形式化方法（formal methods）的人來說，你其實可以在這個層級上驗證演算法的行為。

你可以說，我可以針對這個不確定性設定一些邊界，然後我會在這些已知邊界內安全地運作，我們的模型就是這樣運作的。所以當我們談到 security 的問題時，我們可以做的是，把攻擊看成是對這張因果依賴圖的介入（intervention）。我應該先說明，這裡我只凸顯了四個節點，實際上你會針對特定情境裡所有重要的事物，建構一整張因果依賴圖。而 security 事件會擾動這些關係，我們實際上會把攻擊造成的效果一路傳播下去，直到某個安全指標出現最終的偏差。在這個案例中，我們關心的指標是與另一艘船的最近接近點（closest point of approach）。

這個數值越小，情況就越危險，發生碰撞的可能性也越高。接下來是到達最近接近點所需的時間。時間真的很重要，尤其取決於船有多大、操縱性有多好。你需要能夠在夠早、夠遠的距離之外就預測出最近接近點，好讓船艦有足夠時間採取迴避動作。而攻擊接著就會沿著這些因果結構傳播下去，讓對船艦位置的估計逐漸劣化，比如在影像攻擊的案例中，實際改變了它對眼前狀況的認知，最終導致這個安全指標，也就是最近接近點或到達所需的時間，出現劣化。所以我們能做到的，是找到方法，把實體安全分析，跟傳統的資安手法，以及像偽造攝影機、實體攻擊這類比較非傳統的手法整合在一起。

所以在真實世界中，我們仍然必須持續關注所有那些傳統的 security 議題。但總結來說，在這些資訊實體系統中使用 AI，帶來了新的挑戰。我們的攻擊面大幅擴張，如果使用大型語言模型，還會涉及訓練資料、提示詞（prompt）、上下文等等。同時也存在實體攻擊面，最明顯的例子就是偽造影像，但你其實也可以在其他電磁領域做到類似的事。不過，有一件我們在 safety 上、甚至在某種程度上在 security 上，通常不太會去在意的事，就是事件發生的時間順序（time ordering）。我們之所以想分析這個問題，其中一個原因，是它其實顯示出，事件的時間順序本身，可能就足以突破防禦。

所以我或許已經讓某一個 agent 變得安全了，但實際上只要改變事件發生的時間順序，我就能破壞整個代理型生態系統的 safety 與 security。所以結論是，我們確實需要研發新的分析方法，把 safety 與 security 整合在一起。我們基於這些結構因果世界模型所做的，就是達成這個目標的其中一種可能方法，目前我們也正在把它擴展，納入世界模型中關於 agent 與人類之間，在有對話介面時共同理解的概念。我真正希望大家從這場演講中帶走的重點是：如果你是做 security 的，請務必來找我們這些做 safety 的人聊聊。這兩個議題交互作用的地方，會出現全新的挑戰。
