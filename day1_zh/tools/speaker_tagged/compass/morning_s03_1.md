過去 30 年，網際網路服務的對象其實只有一種客戶，就是人類。所有的支付軌道、營利模式，一切都是為這一種客戶——人類——量身打造的。所以你有註冊流程、訂閱模式、應付帳款，還有廣告，對吧？但現在出現了一種新型態的客戶，就是 AI 代理人。而 AI 代理人與網際網路互動、行為的方式，跟人類完全不一樣。它們消化資訊的能力比任何人類都要高出好幾個數量級。這一點你可以親自驗證：只要用你的 Claude 跑一個簡單的深度研究查詢，你就會看到它能在幾秒鐘內讀完數百頁的資訊。

而網路上有些頁面，或者說有些文章，是設有付費牆的，這也合理，因為商家會想：這是優質內容，我要讓人類為它付費。所以一旦代理人碰到付費牆，就無法繼續存取，你的研究品質也就因此打了折扣，因為它無法觸及那個優質資源。而另一邊，商家設置這些付費牆是為了將內容變現，但他們現在逐漸意識到，出現了這樣一批新客群，與其向他們收訂閱費，不如針對代理人收取一小筆金額，讓它為那一篇文章、那一筆資料或某次推論單獨付費，藉此獲利。既然如此，為什麼不順勢把它變現呢？而且代理人的流量其實正在相對人類流量持續上升，這對商家來說正是把優質內容與資源變現的機會，做法就是用傳統訂閱制的一小部分價格，提供同樣的服務。

這就是整個問題所在。但你可能會問：那為什麼不乾脆讓代理人管理我的訂閱，或直接給它一張信用卡？沒錯，這樣是可行的。你可以給代理人幾個訂閱和 API 金鑰讓它管理，但這樣做規模化得起來嗎？因為今天你想要做任務 X，明天你想要別的東西，那當代理人自己發現某項資源，覺得「這個資源看起來有價值，我想存取它」的時候，你要怎麼替它付費或訂閱那個東西？結果就是卡住了。這就是挑戰所在。你可能又會說，好，那就用信用卡吧。如果你能接受把信用卡資訊交給代理人，那當然沒問題，可是這樣一來經濟效益也不划算。

原因是，我剛才提到，商家現在是用極低的成本把這些端點或資源開放給代理人使用。如果一個代理人為了取得優質內容，高頻率呼叫 API，每次只要付一分錢，卻要額外負擔 3% 或 2.5% 的信用卡手續費，這在經濟效益上根本說不通。所以傳統支付軌道並不適合 AI 代理人做這種即用即付的支付。代理人真正需要的，是像網際網路一樣運作的支付方式：即時、低成本、可程式化，而且全天候可用。這正是 Circle 打造 Circle agent stack 的原因，這是一個為代理人經濟打造的全端平台。我們一起來看看 agents.circle.com。如果大家有帶筆電，我們可以開始這場工作坊，我這邊有幾位同事正在幫大家收集電子郵件，會發放一些 USDC 讓大家在這趟互動旅程中試著打造一門生意。
