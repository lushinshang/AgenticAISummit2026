**Mohamed Nabeel：** 瀏覽器已經是新型的作業系統，所以了解這個攻擊面對我們來說非常重要。我想跟大家分享一些我們透過研究發現的真實案例。在那之前，我想先做個小調查，看看在座有多少人遇過，我相信大家大概都用過某種聊天機器人。有多少人在向它詢問一個事實時，遇過它自信滿滿地告訴你某件事是真的，結果卻是幻覺（hallucination）？好，看來大家都很有感。幻覺出現的程度，其實會依你問的問題而有所不同。現有的研究，甚至連基準測試（benchmark），大多是針對摘要任務中的幻覺，而不是針對供應鏈安全或相關產物的幻覺。

所以在這場演講中，就像我剛才說的，我們要在攻擊者把這些「幽靈」復活之前，先在瀏覽器擴充功能裡把它們找出來。在那之前，先說一個小插曲。前陣子，我有個年幼的女兒，她問我：「爸比，如果我站在火星上看天空，日落會是什麼顏色？」我不想讓她失望，就跟她說讓我查一下再回答她。於是我打開我最愛用的聊天機器人，問了日落會是什麼顏色。它很漂亮地描述說日落會是紅色的，還加了很多優美的形容。我把答案告訴女兒，她很開心我找到了答案。但事實證明，火星的日落並不是紅色。

有沒有人知道是什麼顏色？

答案是藍色。原因是，大型語言模型（LLM）把我們在地球上看到的現象，直接類推套用到火星上，再加上火星本身有「火星天空」這個說法，於是它就用這些事實推論出日落是紅色的。但理論上的事實是，紅光波長較長，可以穿透微粒；藍光波長較短，這就是為什麼，即使是在火星上運行的探測車拍到的照片，看到的也是藍色。這只是個小插曲。從那之後，我都會養成雙重確認答案的習慣。安全領域中的幻覺，並不是一個假設性的問題。已經有研究顯示，PyPy 與 NPM 套件裡都有幻覺現象，我們最近也針對網域名稱的幻覺做了研究。為什麼這個問題在瀏覽器裡特別重要？因為瀏覽器擴充功能是很危險的。它們擁有過度的權限，能看到你的 session token、cookie，一旦這些遭到入侵，攻擊者就等於拿到了通往你作業系統的最前排座位。而這種攻擊手法其實簡單到令人意外。

攻擊者不需要真的入侵系統，他們只需要騙過 AI，讓它幫忙開門，基本上就是利用某種幻覺。之所以會出現這個問題，是因為 LLM 運作方式本身的固有特性。接下來我要展示所謂的「幻覺好發區」（hallucination prone zone），也就是 LLM 表現特別不好的區域。我們看到的其中一個最大趨勢是，因為 AI 的興起，擴充功能的數量正在暴增，現在每個月大約會出現 2 萬個擴充功能。以前，這麼多的擴充功能是整整一年才會出現的量。LLM 並不擅長偵測「新近性」（recency）。所以它們會試著產生幻覺，還想要表現得很樂於助人。另外，在這些擴充功能被建立的同時，大約也有數千個擴充功能被刪除。

而 LLM 並不是「快照式」的學習者。它們對於已刪除的擴充功能沒有概念，仍然以為那些擴充功能還存在。第三個原因是，並非所有擴充功能都有品牌識別。這也會導致 LLM 產生幻覺。這些就是一些 LLM 產生幻覺、憑空捏造出來的擴充功能。它們都是真實存在過的擴充功能，但都已經被刪除了，而且其中許多在瀏覽器擴充功能商店裡也被標記為惡意軟體。這裡是另一組擴充功能，它們根本沒有被任何人申領，但 LLM 卻很自信地把它們幻覺出來，直到現在你都還能安裝它們，攻擊者就可以利用這一點來進行攻擊。最後一張投影片，這些是我們持續在監測的擴充功能。我們一直在對這些擴充功能重新評分，並持續監測這些高幻覺率的擴充功能。

在我們做完這項研究之後，我們發現大約有十幾個擴充功能被註冊、並被用於惡意活動。所以這裡的重點結論就是，不要盲目相信瀏覽器給你的推薦，一定要養成雙重確認的習慣，因為這是 LLM 本身固有的特性，幻覺是永遠不會消失的，你必須隨時對拿到的結果進行事實查核。
