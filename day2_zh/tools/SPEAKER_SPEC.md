# 發言者標註規格

目標：在譯文的每次發言前標上發言者，換人處切段。**一個字都不可以改動譯文。**

實測顯示座談會有將近六成的段落內部就換過人（主持人問完、與談人立刻接話被併在同一段），
所以只在段首標一個名字會把後半段的話掛到別人頭上——這比不標更糟。務必切開。

## 你會拿到

- 該場議程的講者名單（姓名、職稱、角色），來自官方議程表
- 英文原文段落（自動轉錄，含自我介紹、稱呼對方名字等線索）
- 對應的繁中譯文段落（與英文段落一一對應，段號相同）

## 你要輸出

標註好的譯文全文，寫進指定檔案。格式：

```
**Megan Morrone：** 大家好，我是 Megan Morrone，我負責編輯 Axios AI Plus 電子報。

**Matt White：** 謝謝妳的介紹。我想先從開源這件事講起。

**Megan Morrone：** 那 Dima 你怎麼看？

**Dima Dmytro Dzhulgakov：** 我們在 Fireworks 的做法不太一樣。
```

- 每次發言前加 `**姓名：** `（粗體姓名、全形冒號、粗體收尾後接一個半形空格）
- 同一人連續講很長，中間不必重複標；**換人才標**
- 原本的段落分隔（空行）全部保留
- 一個段落裡若換過人，在換人處插入空行切成兩段，各自標上發言者

## 絕對禁止

- **不可以改動、重寫、摘要、補寫任何譯文文字**——你只能加 `**姓名：** ` 前綴和換行
- 不可以刪除既有的 `[?]` 記號、`<!-- 轉錄不清 -->` 註解、`>` 引言區塊、`##` 標題、講者清單
- 不可以合併原有的段落
- 不可以憑空發明講者名單以外的真實姓名

程式會自動比對：把你的輸出移除 `**姓名：** ` 標記、去掉所有空白之後，必須與原譯文完全一致。
只要有一個字不同就會被退回重做。

## 姓名怎麼寫

1. **一律用講者名單上的拼法**，不要照英文轉錄的音譯（轉錄常拼錯姓名，例如把 David Hsu 轉成 "david shoe"）。
2. 判得出是名單上哪一位，就寫真名。
3. 判不出真名，用角色代號：`主持人`、`與談人 A`、`與談人 B`、`提問者`、`工作人員`。
   同一個區塊裡，同一個代號要始終指同一個人。
4. 名單上沒有、但明顯是另一個人（臨時上台、現場提問、代打講者），用 `提問者` 或 `與談人 X`。

## 可用線索

- 自我介紹：`I am Megan Morrone`、`my name is…`
- 被點名：`Thanks, Richard.`、`Ed, what do you think?`、`let's start with you, Matt` → 下一句通常換成被點名的人
- 主持人語氣：提問、控場、報時間、介紹下一位
- 講題內容對應到名單上某人的職稱或公司（例如「I work for Google」對上名單裡的 Google 講者）
- 交接語：`I'll hand it over to…`、`謝謝你，Dan。接下來…`
- 句法習慣：非母語者的固定說法可以幫忙區分不同人

## 標題與非發言內容怎麼處理

- `##` 開頭的議程標題、`**講者**` 清單、`- ` 條列、`>` 引言區塊：**原樣保留，不要加發言者前綴**
- 只有實際的發言段落要標
